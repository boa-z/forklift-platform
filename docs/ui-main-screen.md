## 3. 素材目录映射（从参考工程 `lvgl_src/lvgl_data/` 挑选）

| 用途 | 目录 | 说明 |
| --- | --- | --- |
| 主背景 | `bg/` | `main_bg.png`（主界面），`camera_bg.png` 用于相机屏 |
| 主屏控件 | `src/` | 叉车、转向灯、档位、路面、按钮、锁、相机/语音图标等 |
| 通用状态 | `status/` | `104_status_seat_*`、`104_status_seatbelt_*`、档位 `D/N/P/R`、`distance1..3` 等 |
| 底部导航 | `src/`（`home_*`/`find_*`/`error_*`/`set_*`）或 `menuBar/` | 与参考实现同样式 |

参考工程从运行期配置构建图片路径表（`LvglMainScreen_LoadImgPathConfig`），因此
**文件名与 IMG_ID 的对应需要按语义挑选并在真机/预览中视觉核对**；核对结果回写
到 `ui/src/screens/main/layout.ts` 的素材字段。

## 4. 空数据与质量显示

- 信号 `Stale` / `Unavailable` 时数字显示 `--`（车速、SOC、工时、里程、转向角、雷达）。
- 故障图标由 daemon 的 `FaultSnapshot` 驱动，不由本屏推导。
- 网络类图标（GPS/信号/网络/蓝牙）在无网产品上永不显示。

## 5. 实现注记

- PocketJS 无圆弧图元：车速以数字呈现（与参考一致），转向角同样为数字；
  未来如需指针表盘按 `implementation-plan.md` §4.3 的 spike 结论处理。
- 布局常量集中在 `ui/src/screens/main/layout.ts`，组件不写魔数。
- 交互：模式/相机/语音/锁为点击按钮；底部四页签负责导航；
  倒车雷达与超速由状态触发显隐。
