## 3. 两处一致、当前实现据参考落地的点

- 电量条为 10 段贴图（绿 >20%、黄 11–20%、红 ≤10%），宽 662×26。
- 自检 6 项：CAN 通讯、牵引控制器、油泵控制器、转向控制器、转向角度传感器、
  超声波雷达；进度条 626×18；「进入系统」按钮 206×52。
- 故障行格式 `T  编号  说明`，行右侧警示图标。
- 设置三级菜单与文案（用户/本地/高级），语言表来自 `data.bin`。
- USB 插入提示（移除屏）、CAN 波特率/版本/里程显示等设置项与参考一致。

## 4. 渲染设计稿的方法（供后续核对）

```sh
python3 - <<'EOF'
import fitz
doc = fitz.open("/Users/boa/Downloads/images/20260608 D70T界面设计 x 1.08(最最新).ai")

    page.get_pixmap(matrix=fitz.Matrix(2, 2)).save(f"/tmp/design-pages/page-{i:02d}.png")
EOF
```
