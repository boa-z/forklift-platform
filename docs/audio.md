# 提示音与报警语音

复刻参考工程的语音体系：14 段提示/报警语音（多语言）+ 开机音 + 按钮音，
由报警引擎按门限与节拍触发。

## 2. 产品实现

- **协议 v4**：`SoundId` 追加语义编号（cardSwipe/cardOk/cardFail/overspeed/
  overspeedHigh/overspeedCritical/seatbelt/seatOff/obstacle*/collision）。
- **报警引擎**（`ui/src/platform/alarms.ts`）：按参考的 50ms 拍推进；
  超速逐拍请求（三档）、倒车逐拍请求、故障与安全带/离座 5 秒一次
  （交替类型）；请求顺序即优先级（超速 → 倒车 → 故障 → 安全带/离座）。
- **语音控制器**（`ui/src/platform/voice.ts`）：单播放器；报警语音播放中丢弃
  新请求（参考 `ThreadPlayer_AudioPlay` 返回 -2 的语义），按钮/开机音可打断；
  语言后缀按当前界面语言选择，缺失回退中文。
- **资产**：`tools/make-voice-assets.sh` 从参考工程复制 14 段中文语音并重采样
  到 22050 Hz（参考为 24000，PocketJS 规范只允许 44.1/22.05/11.025k），
  经 `ui/pak.json` 烘焙为 pak 的 `audio:wav.*` 原始块。
- **播放**：PocketJS 宿主 audio 模块（d211 用 `aplay -t raw` 子进程 + 设备时钟
  节拍）；宿主未挂载 audio 模块时静默降级（开发/模拟）。

## 3. 与参考的差异

- 雷达语音（05/13/14）暂按「倒车即播 05」处理：平台还没有超声波雷达数据
  （M3 接入探头后按 <50/<150 门限切 14/13）。
- 授权屏语音（01/02/03）随授权屏一起实现（当前为离线占位）。
- 参考的按钮音与语音可能是两条播放通路；本实现为单播放器（框架播放器的
  poll 是模块级队列，两个播放器会互相消费 credit），按钮音打断语音。
- 参考的语音是 24000 Hz 原始文件；本实现重采样到 22050 Hz（语音质量影响可忽略）。

## 4. 设备验证（D211）

- 开机：`audio createStream 44100 ch=2` → 开机音播放。
- 超速场景（mock 80 km/h）：连续循环播放 10 号语音，间隔 3.2 秒（与剪辑
  时长 3.19 秒一致）。
- 故障场景（mock faultId 4）：每 5 秒一次 4 号语音。
- 倒车场景：1.8 秒循环（中文 05 号语音时长 1.82 秒）。
- 亮度回归：设置滑条写 `/sys/class/backlight`。

宿主侧实现与修复（credit 合并上报、feeder 设备时钟节拍、aplay 150ms 缓冲）
见 PocketJS `feat/d211-host-modules`（PR #417）。
